# Kondor 0.27.0

Netflix and other streaming sites can now play protected video, and the developer tools can sit wherever you like.

## Media

- **Protected content**: when a site needs DRM, Kondor offers to download Google's Widevine module with one click, then restarts to play the video.

## Developer tools

- **Developer tools on any side**: dock them below, left or right of the page, or open them in a separate window, from DevTools' own menu or the new Developer Tools submenu. Kondor remembers your choice.

## Fixes

- Developer tools open again in the AppImage.
