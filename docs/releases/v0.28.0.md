# Kondor 0.28.0

Each window now keeps its own layout. Hiding the toolbars, showing the bookmarks bar or collapsing the side bar changes only the window you are in, and new windows start with your last choice.

- **New Window in the launcher menu**: right-click Kondor in the task manager to open a new window, next to New Private Window.
- **Searching from the address bar**: typing a space after a word that matches a site you visited no longer completes the site's address, so you can go on typing a search.
